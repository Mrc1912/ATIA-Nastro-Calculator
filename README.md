# ATIA Nastro Calculator

Applicazione Android per il calcolo dei parametri di un nastro trasportatore.

## Funzioni

- giri del rullo dal rapporto di riduzione;
- velocità del nastro in m/s e m/min;
- tempo di percorrenza in base alla lunghezza del nastro;
- rapporto di riduzione necessario partendo dalla velocità desiderata;
- tutti i parametri sono modificabili.
- sezione crediti con logo ATIA e collegamento a [www.atiafooddevice.com](https://www.atiafooddevice.com).

## Scaricare l'APK

Aprire **Actions**, scegliere l'ultima esecuzione verde di **Compila APK Android** e scaricare l'artefatto **ATIA-Nastro-Calculator-APK**.
